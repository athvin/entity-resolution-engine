# Search and AI answer test prompts

Run these monthly in Google, Bing, ChatGPT, Claude, Perplexity and Gemini, in a
signed-out or fresh session where the platform allows it, and record what you
see. The aim is to notice change over time, not to hit a target: a result here
is one sample, and answers vary between runs.

Record for each run: the date, the platform, whether DupeZero appears, how it
is described (and whether that description is accurate), and which sources the
answer cites.

live site: pricing is based only on total records; there is no SSO and no
certification today. A wrong description is worth tracing to its cited source.
