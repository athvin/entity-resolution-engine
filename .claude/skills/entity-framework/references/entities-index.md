Reading the table:

- **Store** is which database the entity lives in. `duckdb` means the lake,
  `postgres` the control plane. A statement is planned against its own store
  only.
- **Key** is the primary key, which is `id` for every entity by convention.
- **Natural key** is the upsert identity: a MERGE's `ON` clause must match it
  exactly (E015), and those columns are immutable (E005).
- **History** marks entities with a jsonb row-image companion table, written by
  a trigger.

The second table counts declared statements per operation. An entity with no
statements is read or written only through the engine's own stage SQL, not
through a typed query function.
